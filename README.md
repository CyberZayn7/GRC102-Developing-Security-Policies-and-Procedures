## Project Overview

This project presents a comprehensive Information Security Policy Framework for ICDFA. The report demonstrates how governance, policies, standards, procedures, and guidelines work together to create an effective security management structure.

## Objectives

- Establish a policy governance framework
- Develop core security policies
- Map controls to ISO/IEC 27001:2022 and NIST CSF 2.0
- Define implementation and communication strategies
- Create a formal exception management process
- Design policy effectiveness metrics
